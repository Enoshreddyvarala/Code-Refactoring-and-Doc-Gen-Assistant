0 CaptionAI: AI-Powered Social Media Caption Generator
1 Project Description:
2 CaptionAI harnesses Generative AI to provide intelligent social media content generation, offering users a fast and personalized caption-creation experience. The platform includes a Caption Generator module, which produces three unique, platform-optimized captions per request, a Hashtag Suggester, which generates ten relevant hashtags blending popular and niche tags, and a Call-to-Action (CTA) Generator, which delivers three punchy, action-oriented phrases tailored to the selected tone and platform.
3 
4 Utilizing Groq’s API with the LLaMA 3.3-70B Versatile model, CaptionAI processes user inputs to deliver fast, high-quality social media content. Built with Flask and deployed publicly via Ngrok, the platform ensures a seamless and user-friendly experience. With secure API key management via .env and responsible input handling, CaptionAI empowers marketers, creators, and businesses to craft compelling social media content with confidence.
5 Scenarios
6 Scenario 1: A user describes a new summer collection of sustainable sunglasses and selects Instagram with a Casual tone. The system generates three emoji-rich captions optimized for Instagram’s visual-first audience, ten relevant hashtags mixing broad and niche tags, and three punchy CTAs all in seconds.
7 
8 Scenario 2: A user promoting a B2B SaaS product selects LinkedIn with a Professional tone. CaptionAI generates thought-leadership-style captions with a value-driven narrative, industry-relevant hashtags, and CTAs designed to drive professional engagement such as demo sign-ups or article reads.
9 
10 Scenario 3: A user running a weekend flash sale selects Instagram with a Promotional tone. The AI generates urgency-driven captions filled with power words, a curated hashtag set targeting deal-seekers, and CTAs like “Shop before it’s gone!” to maximize conversion.

166 /generate — POST endpoint that accepts JSON input, invokes the AI, and returns structured content
167 @app.route("/generate", methods=["POST"])
168 def generate():
169     data = request.get_json()
170     product_info = data.get("product_info", "").strip()
171     platform = data.get("platform", "instagram").lower()
172     tone = data.get("tone", "professional").lower()
173     if not product_info:
174         return jsonify({"error": "Product information is required."}), 400
175     if len(product_info) > 2000:
176         return jsonify({"error": "Input too long. Please keep it under 2000 characters."}), 400
177     try:
178         prompt = build_prompt(product_info, platform, tone)
179 
180         chat_completion = client.chat.completions.create(
181             messages=[
182                 {
183                     "role": "system",
184                     "content": "You are a social media content expert. Always respond with valid JSON only, no markdown formatting."
185                 },
186                 {
187                     "role": "user",
188                     "content": prompt
189                 }
190             ],
191             model="llama-3.3-70b-versatile",
192             temperature=0.8,
193             max_tokens=2048,
194         )
195         response_text = chat_completion.choices[0].message.content
196         result = extract_json(response_text)
197         # Validate structure
198         if not all(k in result for k in ["captions", "hashtags", "ctas"]):
199             raise ValueError("Invalid response structure from AI")
200         return jsonify({
201             "success": True,
202             "captions": result["captions"],
203             "hashtags": result["hashtags"],
204             "ctas": result["ctas"],
205             "platform": platform,
206             "tone": tone
207         })
208     except ValueError as e:
209         import traceback
210         traceback.print_exc()
211         return jsonify({"error": f"Failed to parse AI response: {str(e)}"}), 500
212     except Exception as e:
213         import traceback
214         traceback.print_exc()
215         return jsonify({"error": f"Generation failed: {str(e)}"}), 500

268 Integrate the Groq AI Responses in Each Function:
269 Call client.chat.completions.create() with a system message enforcing JSON-only responses and a user message containing the assembled prompt.
270 extract_json(): a robust parser that first attempts direct json.loads(), then strips markdown code fences (```json blocks), and finally uses a regex to locate a raw JSON object ensuring reliable parsing across model response variations.
271 def extract_json(text: str) -> dict:
272     """Extract JSON from LLM response, handling markdown code blocks."""
273     # Try direct parse first
274     try:
275         return json.loads(text)
276     except json.JSONDecodeError:
277         pass
278     # Try extracting from markdown code block
279     match = re.search(r'```(?:json)?\s*([\s\S]*?)```', text)
280     if match:
281         try:
282             return json.loads(match.group(1).strip())
283         except json.JSONDecodeError:
284             pass
285     match = re.search(r'\{[\s\S]*\}', text)
286     if match:
287         try:
288             return json.loads(match.group(0))
289         except json.JSONDecodeError:
290             pass
291     raise ValueError("Could not extract valid JSON from response")
